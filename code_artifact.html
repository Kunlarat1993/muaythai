บันทึกการสะท้อนผลของคุณ:

พื้นที่สำหรับครูผู้สอน

คำแนะนำการใช้งานแอปพลิเคชันสำหรับครู

  • การใช้ AR สแกนคำตอบ: เกมนี้เน้นให้ใช้กล้องสแกน AR เพื่อตอบคำถาม ครูต้องเตรียม QR Code หรือรูปภาพสัญลักษณ์ (Marker) ที่ระบุว่าเป็นคำตอบ ก, ข, ค ไปติดไว้ตามจุดต่างๆ ในพื้นที่เรียน
  • สำหรับการทดสอบบนเว็บ: เมื่อเปิดกล้องสแกน จะมีปุ่มจำลองด้านล่างเพื่อให้กดสมมติว่าสแกนเจอคำตอบนั้นๆ แล้ว เพื่อให้ใช้งานแอปได้แม้ไม่มีรูป QR Code จริง
  • หากอินเทอร์เน็ต/กล้องมีปัญหา: มีปุ่ม "ดูสื่อสำรอง" เพื่อแสดงภาพเนื้อหาให้แทนได้
